# Overview

I'm building this software as a first step in setting up my development workflow and getting comfortable writing, running, and publishing code to a public repository. This "Hello World" program is intentionally simple: it prints a short greeting to the screen, personalized with my name.

My purpose in creating this program was to confirm that my development environment (editor, Python interpreter, Git, and GitHub) is all working correctly together before moving on to more complex software, and to establish the workflow I'll use for documenting and sharing every project going forward.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I wrote and ran this program using Visual Studio Code as my editor, with Git for version control and GitHub for hosting the public repository.

I used Python 3 as the programming language, running it directly from the terminal with the `python3` command.
